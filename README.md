# Гардарика — творческий коллектив

Современный информационный сайт творческого коллектива «Гардарика»: 14 шоу-направлений, форматы мероприятий, проекты, реализованные кейсы и контакты.

## Ссылки

- Публичный сайт: https://gardarika-show.semenovspb.chatgpt.site
- Официальные материалы: https://gardarikashow.ru/
- VK: https://vk.ru/gardarika_show

## Что входит

- адаптивная мобильная и десктопная версия;
- фотографии для всех 14 шоу-программ;
- проекты «Гардарика», «Русское подворье» и «Праздники События»;
- контакты, WhatsApp и ссылки на публичные материалы;
- исходники Vinext/React и ресурсы, необходимые для сборки.

PDF-буклеты намеренно не хранятся в репозитории. Кнопки буклетов ведут на опубликованные версии сайта.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm run install:ci
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```
